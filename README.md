## About myreminderapp
<p>This is the reminder which remind you triggered by datetime or location</p>

## Reason why I made it
<p>To resolve my partner's problem.</p>
<p>My partner struggles to remember what he needs to buy something by when at where.</p>
<p>He needs the reminder app which has both triggers location and datetime but there was no apps in Google Play as far as we checked.</p>
<p>Also, I would like to learn Laravel so I decided to built this app</p>

## Features
- datetime reminders
- location reminders
    - You can choose locations by marker on Google Map on reminder creation page
    - Send reminders when the distance between you and the location is less than 50m
    - Your current location would be sent to this app after you move 10m
- Show reminders by red color text if the reminders are already notified
- Update reminder contents
- Complete reminders
